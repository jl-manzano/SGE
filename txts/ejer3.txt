// ==================== EJERCICIO 4: GESTIÓN DE CURSOS Y ESTUDIANTES ====================
// 
// ENUNCIADO:
// Gestionar cursos y estudiantes en una institución educativa usando Clean Architecture y MVVM.
// 
// FUNCIONALIDADES:
// - Agregar cursos: nombre, descripción, fecha inicio, fecha finalización
// - Agregar estudiantes: nombre, edad, curso asignado
// - Asignar estudiantes a cursos (1 estudiante = 1 curso máximo)
// - Mostrar estudiantes por curso: nombre, edad, curso
// - Actualizar datos de estudiantes y asignación de cursos
// - Eliminar estudiantes y cursos (reubicar/eliminar estudiantes huérfanos)
// 
// VALIDACIONES:
// - Edad estudiante >= 18 años
// - Un estudiante en máximo 1 curso
// - Fecha inicio < Fecha finalización
// 
// REQUERIMIENTOS TÉCNICOS:
// - MVVM: Lógica de negocio separada de la vista
// - Clean Architecture:
//   * Dominio: Entidades (Estudiante, Curso)
//   * Aplicación: Casos de uso
//   * Infraestructura: Repositorios
//   * UI: Controladores y vistas
